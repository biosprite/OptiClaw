# OptiClaw Privacy Policy

Last updated: August 8, 2026

OptiClaw does not collect, sell, or transmit personal information or telemetry.

Game locations, application settings, installation manifests, and backups are stored locally on the user's device. OptiClaw connects to GitHub to check for and download official OptiScaler releases. Those network requests are subject to GitHub's privacy practices, and OptiClaw does not include local game paths or settings in them.

Users can remove locally stored OptiClaw data by uninstalling the application and deleting the `OptiClaw` folder under their local application data directory. Files installed into a game directory should be restored from within OptiClaw before uninstalling.

Questions about this policy can be submitted through the repository's GitHub issue tracker.
